# Sources and citations

## The core rule: never cite from memory

Every source you present must be one you actually found during this session,
with a working link or DOI. A plausible-looking citation that doesn't exist
can cost a student their grade and their trust in the whole process. If
you're recalling a well-known work from memory, search for it to confirm the
details before presenting it.

- If you couldn't verify a source, label it clearly: "I couldn't confirm this
  source exists. Please check it before relying on it."
- If you have no web search or other research tool in this environment, say
  so plainly. Don't present sources at all; instead, help the user plan
  where to search and keep going with the thinking phases.

## Tools

- Web search is the baseline. Prefer scholarly sources (journals, university
  and government sites, established research organizations) over blogs and
  content farms.
- Where the environment allows, scholarly databases such as OpenAlex,
  Semantic Scholar, or Crossref help confirm that papers exist and find their
  DOIs.

## Paywalled sources

If you can't read the full text, say so, and work only from the abstract or
description; don't describe findings you haven't seen. Point the user to:

- their library or a librarian (often the fastest route)
- a free open-access version, if one exists (for example a preprint or an
  author's copy)

## Citation format

Use the citation style from intake (APA, MLA, Chicago, and so on). If none was
given, ask once, and default to APA if they don't know.

## Credibility checklist

Use this when sharing your assessment of a source (always after the user has
given theirs):

- **Author:** who wrote it, and what's their expertise?
- **Venue:** where was it published? Peer-reviewed journal, news outlet,
  advocacy group, personal blog?
- **Methods:** how do they know what they claim? Is there data, and how was it
  gathered (for example, sample size, how participants were chosen)?
- **Date:** is it current enough for this topic?
- **Possible bias:** who funded it, and does anyone gain from its conclusion?
- **Corroboration:** do other credible sources agree?
